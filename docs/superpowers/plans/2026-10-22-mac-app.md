# CarBUS.app Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Обычная программа для Mac (`CarBUS.app` в `.dmg`): двойной щелчок открывает своё окно с интерфейсом, прибор находится по USB, без Docker, Терминала и моста.

**Architecture:** Окно на Swift (AppKit + WKWebView) запускает встроенный python-build-standalone с бэкендом (`python -m app.desktop`): сервер на `127.0.0.1:47800`, мост выключен, при пропаже окна бэкенд завершается сам. Python и зависимости ставятся для arm64 и x86_64 и сшиваются `lipo` в один универсальный пакет; подпись ad-hoc; `.dmg` собирает `macos/build-app.sh`, выкладывает GitHub Actions по тегу `v*`.

**Tech Stack:** Swift 6 / AppKit / WebKit (swiftc без Xcode-проекта), python-build-standalone CPython 3.12.15, FastAPI/uvicorn/carbus-lib (как в `backend/pyproject.toml`), Preact (vitest), bash, hdiutil, codesign, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-22-mac-app-design.md`

## Global Constraints

- macOS не ниже 12.0 (`LSMinimumSystemVersion` 12.0); окно — универсальный Mach-O `x86_64 arm64`.
- Python: python-build-standalone релиз `20261021`, CPython `3.12.15`, `install_only_stripped`; sha256 aarch64 `7b8d00b751db21cea87dc551a8f8165147c5fbc5251d5537d7e5497dde00a219`, x86_64 `f12e0504397683d6be0745ffd4c39ef45a455cec169adf35c628840d06133773`.
- Зависимости — ровно `[project].dependencies` из `backend/pyproject.toml` с `-c backend/constraints.txt`, только колёса (`--only-binary=:all:`).
- Bundle id `com.scryptor.carbus`, имя `CarBUS`; порт `47800`, занят — свободный порт от системы.
- Данные: `~/Library/Application Support/CarBUS/data` и `…/traces`, журналы `~/Library/Logs/CarBUS/app.log` и `backend.log`; `CARBUS_HOME=<dir>` (только для тестов) переносит всё это в `<dir>`.
- Пакет не пишет в себя: `.pyc` собраны `compileall --invalidation-mode unchecked-hash`, бэкенд запускается с `PYTHONDONTWRITEBYTECODE=1 PYTHONNOUSERSITE=1`.
- Подпись только ad-hoc: `codesign --force -s -` на каждый вложенный Mach-O, затем на пакет; `codesign --verify --deep --strict` чистый.
- В окне программы нет слов «мост», «Docker», `run-bridge` (режим без моста). Docker-вариант не меняется.
- Тесты не передают в шину. Живая проверка с прибором — «Только слушать», не дольше минуты.
- Коммит — после показа `git status` и сообщения; push и тег — только по просьбе Игоря.

## Review Focus

1. Порт 47800 занят другой программой — программа всё равно открывается (на другом порту). Тест: `macos/test-app.sh`, случай «port-busy» (Task 4).
2. Окно убито (`kill -9`, сбой) — бэкенд не остаётся держать USB-порт прибора. Тесты: `test_desktop_exits_when_parent_dies` (Task 2) и случай «orphan» в `macos/test-app.sh` (Task 4).
3. Программа запущена прямо из `.dmg` (только чтение, App Translocation) — работает, ничего не пишет в себя. Тест: случай «read-only» в `macos/test-app.sh` с примонтированным `.dmg` (Task 5).
4. Путь к данным с пробелом и кириллицей (`Application Support`, имя пользователя) — бэкенд стартует. Тест: `CARBUS_HOME` с «Тест папка» в `macos/test-app.sh` (Task 4).
5. Intel-мак — x86_64-ломтики Python и колёс грузятся. Тест: импорт под `arch -x86_64` в CI (`.github/workflows/mac-app.yml`, Task 5); локально Rosetta нет — проверяется `lipo -archs` всех Mach-O (Task 4).
