# CarBUS for Mac

Веб-инструмент для программатора **CAN-Hacker v3.2** на macOS: живой монитор,
карта бит, поток, запись/просмотр трейсов, передача с триггерами, фильтры,
битрейт. Бэкенд (Python/FastAPI + [`carbus-lib`](https://pypi.org/project/carbus-lib/))
в Docker, интерфейс — в Chrome.

Порт штатного Windows-софта CarBUSAnalyzer. Дизайн и карта восстановленного UI —
в `docs/`.

## Почему нужен мост на маке

Docker Desktop на macOS запускает контейнеры в Linux-VM и **не прокидывает USB**
в неё. Поэтому USB-порт программатора держит тонкий нативный мост на самом маке
(`run-bridge.sh`, штатный `carbus_async.tcp_bridge`), а контейнер подключается к
нему по TCP через `host.docker.internal`.

## Запуск (два шага)

1. Подключите программатор по USB и на маке запустите мост:

   ```bash
   ./run-bridge.sh          # найдёт /dev/cu.usbmodem* и отдаст его на :7000
   ```

2. В другом терминале поднимите контейнер и откройте интерфейс:

   ```bash
   docker compose up --build
   ```

   Затем откройте в **Chrome** <http://localhost:8000>, нажмите **Connect**
   (мост по умолчанию `host.docker.internal:7000`), выберите канал и битрейт.

Трейсы пишутся в `./traces` на маке (примонтировано в контейнер).

## Безопасность

- Интерфейс и WebSocket слушают только `127.0.0.1` мака.
- Мост слушает все интерфейсы (это требование Docker на маке). Держите firewall
  включённым или работайте в доверенной сети.
- Публичный relay из `carbus-lib` (`185.42.26.80`) **не используется** — трафик
  шины наружу не уходит.

## Что умеет v1

Монитор (группировка по ID, подсветка изменений), карта бит выбранного ID, поток,
запись/воспроизведение трейсов, передача (Shot/Run/периодика/триггеры), аппаратные
и диапазонные фильтры, выбор канала и битрейта (пресеты + ручной тайминг).
Вне v1: DBC-менеджер, JS-движок, bruteforce, UDS, LIN, CAN-FD.

## Разработка

```bash
# бэкенд
cd backend && python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
.venv/bin/pytest -q
# на реальном железе: запустить мост, затем
CARBUS_BRIDGE=127.0.0.1:7000 .venv/bin/pytest -q tests/test_carbus_session_smoke.py

# фронт
cd frontend && npm install
npm run test        # vitest (чистые помощники)
npm run dev         # vite dev-сервер
```
